# Proyecto Restaurante - Archivo de Versiones
### Criterio de versionado:
- Se utiliza el esquema SemVer (Mayor.Menor.Patch).
- Cambios mayores: refactorizaciones estructurales, nuevas funcionalidades principales.
- Cambios menores: mejoras en la experiencia de usuario, correcciones de bugs, integración de utilidades compartidas.
- Patch: hotfixes o correcciones menores sin impacto en la API ni en la estructura principal.


## Versión 1.0.0 (26/10/2025)
- Estructura inicial del proyecto backend y frontend.
- Implementación de base de datos y endpoints principales para reservas, facturación y usuarios.
- Integración de Docker para despliegue y desarrollo local.

## Versión 1.1.0 (26/10/2025)
- Refactorización de la lógica del carrito de compras.
- Creación de `public/cliente/cart-lib.js` para centralizar la gestión del carrito (agregar, eliminar, sincronizar, hidratar desde backend, actualizar badge).
- Corrección de la agregación de cantidades y subtotales en el backend (`GET /api/facturas/:id/detalles`).
- Sincronización automática del carrito y badge en todas las páginas relevantes, sin necesidad de refrescar manualmente.
- Pruebas de integración y validación de la experiencia de usuario en el flujo de reservas y compras.
